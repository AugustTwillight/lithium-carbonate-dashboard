# 碳酸锂预测与迭代方法

## 1. 目标

辅助跟踪碳酸锂电池产业链、广期所期货价格、上下游股票、宏观变量和新闻事件，并记录每次预测及事后结果，而不是给出自动交易指令。

## 2. 因子

| 因子 | 数据来源 | 当前计算方式 |
|---|---|---|
| 技术面 | 东方财富期货日线 | 5/20 日动量、MA20/MA60、RSI、波动率 |
| 现货基差 | Trading Economics + 期货 | `(现货 - 期货) / 期货` |
| 宏观市场 | 东方财富指数与商品 | 美元指数、沪深300、纳指、原油的近 60 日相关性与 5 日趋势 |
| 上游供给 | 新闻 + 上游股价 | 供给新闻情绪 + 上游相对下游 20 日动量 |
| 下游需求 | 新闻 + 电池股价 | 需求新闻情绪 + 下游股票 20 日动量 |
| 地缘政策 | 新闻 | 政策、环境、战争和制裁类新闻情绪 |

## 3. 预测

对六个因子做加权：

```text
raw_score = Σ(weight_i × factor_score_i)
probability_up = logistic(3 × raw_score)
expected_return = raw_score × daily_volatility × sqrt(5) × 0.85
price_range = expected_price ± 1.28 × daily_volatility × sqrt(5)
```

预测期限默认为 5 个交易日，目标日期按 7 个自然日近似。

## 4. 权重校准

当预测目标日期到达后：

1. 计算基准价到实际价的方向和收益。
2. 对每个有显著贡献的因子，检查其方向是否与真实方向一致。
3. 命中时奖励该因子权重，未命中时衰减。
4. 将所有权重限制在 3%–45% 并重新归一化。
5. 记录方向命中率、概率误差 Brier 分数和实际收益。

浏览器 localStorage 保存实时模型状态；页面提供 JSON 和 Markdown 下载，以便把状态归档到仓库或外部研究系统。

## 5. 数据限制

- Trading Economics 是现货参考口径，不应与广期所交割标准直接等同。
- 新闻来源是聚合结果，关键词分类可能误判。
- 相关性不代表因果关系。
- 当前版本未接入付费库存、仓单、冶炼利润、长协和矿山成本数据。
- 任何预测都可能失效；期货交易应独立评估保证金、流动性和尾部风险。
