二、更新机制

浏览器实时刷新

点击“联网检索最新数据”后，浏览器直接请求支持 CORS 的东方财富、Trading Economics 代理和新闻 RSS 接口。此方式无需登录 GitHub，打开后即可手动更新。

GitHub Actions 后台快照

仓库中的定时任务每 30 分钟运行一次数据脚本，保存到 data/latest.json。即使 dashboard 未打开，也会积累最新快照；GitHub 可能延迟执行定时任务，不能保证毫秒级实时。
